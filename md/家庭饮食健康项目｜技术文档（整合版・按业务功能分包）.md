## 1. 项目概述与迭代规划

**项目名称**：家庭饮食健康智能食谱系统
**核心目标**：录入家庭成员健康档案 + 家中现有食材，AI 生成适配全家、兼顾每个人特殊需求的个性化食谱；统计营养摄入，生成营养周报、自动生成食材采购清单。

- **一期（必做）**：家庭成员档案管理、多方式食材录入（文字 / 拍照 OCR / 语音）、AI 食谱生成、营养计算、营养周报、采购清单。
- **二期（迭代可选）**：面相 / 舌苔图像分析，辅助饮食建议。

## 2. 业务核心规则定义

### 2.1 食材录入粒度

> 
> 录入格式：`食材名称 + 重量`，例：`番茄 500g`

- 最小录入单元：食材名称 + 数量 + 单位，不可仅录入 “番茄” 不带数量。
- 支持单位：g、kg、个、份；后端统一转换为克作为计算基准。
- 识别兜底：OCR/ASR 识别仅识别到食材名无重量时，前端弹窗提示用户手动补充重量。

### 2.2 营养缺口口径

- 参考标准：《中国居民膳食营养素参考摄入量（DRIs）》
- 监控营养素：能量、蛋白质、脂肪、碳水、膳食纤维、钙、铁、锌、维生素 A/C
- 缺口判定规则：**营养素缺口＞30%**，标记为营养不足。
> 
> 缺口计算公式：`缺口比例 = (推荐摄入量 - 实际摄入量) / 推荐摄入量`

### 2.3 反馈→周报折算规则

1. 用户勾选实际制作菜品，填写**实际食用分量**；
2. service 层读取菜品营养成分表，按【食用分量占菜品总份量比例】折算本次摄入营养素；
3. 按自然周汇总全部用餐记录，计算每周日均摄入，对比 DRIs 标准生成周报；
4. 周报输出：各项营养素摄入占比、缺口标记、饮食优化建议。

### 2.4 档案交互细节

- 字段校验：年龄区间、过敏原使用枚举列表（固定可选，禁止自由文本乱输入）；
- 成员上限：单家庭最多 8 名成员；
- 删除成员：软删除标记，**历史营养、食谱记录保留归档，不再参与新的食谱生成**。

### 2.5 采购清单粒度

- 计算基准：`人数 × 天数`；
- 同类食材合并：同名食材自动合并重量，单位统一换算；
- 导出表格字段：食材名称、总采购重量、推荐单位、备注。

## 4. 模块职责说明

表格

| 模块 | 作用说明 |
| --- | --- |
| `family_member` | 家庭成员档案管理：录入成员年龄、过敏原枚举、减脂 / 控糖等个性化饮食目标；成员增删，软删除处理历史记录；表单字段校验、成员上限控制 |
| `ingredient` | 食材录入，支持文字、拍照 OCR、语音录入；食材信息存储（名称 + 重量，粒度：`番茄,500g`）、家庭食材库存管理 |
| `recipe` | 核心业务：读取家庭成员档案 + 当前可用食材，调用大模型生成全家食谱，区分每个成员个性化食用方案 |
| `nutrition` | 营养计算核心，加载《中国居民膳食营养素参考摄入量 DRIs》，计算营养素缺口；用户实际就餐分量录入，换算生成营养周报 |
| `shopping_list` | 采购清单生成：按「人数 × 天数」计算采购量，同类食材合并，支持导出 Excel 表格 |
| `ai_assistant` | 多模态能力：食材图片 OCR 识别、武汉方言语音 ASR；预留二期面相、舌苔图像分析接口 |

## 5. 分层调用规范 & 代码示例

### 调用链路规范

`Router(接口) → Service(业务逻辑编排) → Repository(数据库CRUD) → DB`

1. router：接收 http 请求，参数基础校验，调用对应 service，返回响应
2. service：业务逻辑编排，营养计算、调用 LLM、业务规则判断，**禁止直接写 SQL**
3. repository：仅实现数据库读写 CRUD，**不包含业务逻辑**
4. models：SQLAlchemy ORM 数据库实体定义
5. schemas：Pydantic，入参校验、出参序列化、数据转换

### 示例代码 `modules/family_member/router.py`

```
from fastapi import APIRouter, Depends
from app.common.deps import get_current_user
from app.modules.family_member.service import member_service
from app.modules.family_member.schemas import MemberCreate, MemberResp

router = APIRouter(prefix="/family-member", tags=["家庭成员档案"])

@router.post("/", response_model=MemberResp)
async def create_member(item: MemberCreate, user=Depends(get_current_user)):
    return await member_service.create_member(item, user_id=user.id)
```

## 6. 技术栈选型

- 后端框架：Python + FastAPI
- ORM：SQLAlchemy（异步）
- 数据库：MySQL
- AI 大模型：第三方 LLM SDK
- 多模态：OCR 图片识别、ASR 方言语音识别
- 营养数据源：《中国食物成分表》、DRIs 膳食标准
- 缓存：Redis（可选，缓存菜谱、营养基础数据）
