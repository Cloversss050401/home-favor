# 家庭 AI 食谱推荐系统 项目整合规划

> 
> 文件：家庭 AI 食谱推荐系统_项目整合规划.md
> 结合原始用户使用说明、产品构思、现有网页版问题，区分一期必做、二期迭代，梳理业务流程、bug 清单、模块依赖

## 一、项目整体目标

网页端家庭饮食健康管理工具。录入家庭成员档案与家中现有食材，AI 生成全家共享食谱、个人分餐方案与营养评估；食材不足输出采购建议；收集用户实际做菜反馈，生成周度营养分析报告。
后续迭代拓展面相舌苔体质识别、对接买菜渠道，形成闭环：**家庭档案 → 食材录入 → AI 食谱生成 → 采购建议 → 用户反馈 → 周营养报告**。

## 二、功能模块划分（按迭代优先级）

### 🟢 一期｜核心必做（优先开发，保障主流程跑通）

#### 1. 家庭成员档案库（核心基础，当前存在存储 BUG）

> 
> 现状：网页食材存储正常，**家庭档案无法保存，导致食谱生成缺少人员数据，无法做个性化校验，属于阻塞主流程 BUG，需要优先修复**

- 数据库存储每个家庭成员信息：
  - 基础属性：年龄、性别
  - 饮食目标：减脂、健身增肌、孕妈、婴幼儿辅食等
  - 体质健康：体质类型、高血压等慢病倾向、气虚 / 体质偏寒等
  - 限制条件：过敏原、饮食忌口
- 支持家庭成员增、删、改；数据持久化存储
- 生成食谱接口可正常读取档案库数据，作为食谱计算的输入源

> 
> 修复要点：网页端修复档案存储逻辑，提交成员信息后持久落库，生成食谱时可正常读取。

#### 2. 家庭现有食材录入模块

支持三种录入方式，录入后食材持久化保存，支持手动编辑：

1. 拍照识别食材
2. 文字手动输入
3. 武汉方言语音录入
4. 手动增删、确认食材列表

#### 3. AI 食谱智能生成引擎

读取【家庭档案库】+【家庭食材列表】，10‑30s 完成营养计算，输出三层结果：

1. **全家共享菜品清单**：一桌统一制作菜品，全部基于当前已有食材
2. **个人分餐方案 + 双维度营养评估**
   - 每位成员专属食用分配（吃什么、食用分量）
   - 摄入优点：匹配个人体质、健康目标
   - 营养缺口：标注营养素缺口占比、缺失数值
3. **食材不足智能采购清单**
   - 触发条件：核心营养素缺口＞30% 或可用主菜不足 2 道自动触发
   - 输出内容：按优先级排序，标注缺失营养素、建议采购量，优先满足缺口最大家庭成员
   - 一期能力：网页查看清单，支持导出表格文件

#### 4. 用户反馈采集 & 周度营养分析报告

1. 用户反馈功能
   - 用户做完菜后，勾选实际制作菜品，填写食用分量，支持填写改进备注；全部按推荐制作支持一键全选
   - 反馈数据持久保存，作为周报告数据源
2. 周营养分析报告
   - 触发方式：手动生成 / 设置每周日自动生成
   - 报告内容：
     1. 每位成员本周营养素（蛋白、碳水、脂肪、维生素、矿物质）摄入达标率、累计缺口、超标项
     2. 本周饮食问题总结
     3. 下周分人饮食调整方向、补充建议

### 🟡 二期｜后续迭代（一期上线后开发，不阻塞主流程）

1. AI 体质图像识别：拍摄面相、舌苔图片，辅助自动补充家庭成员体质信息，优化个性化食谱推荐
2. 采购渠道对接：采购清单对接美团买菜等第三方，支持从清单直接跳转商品购买页面

## 三、标准业务操作流程（修正原有页面逻辑混乱问题）

> 
> ⚠️ 前置前提：必须修复家庭档案存储 BUG，否则后续流程无法正常计算

1. **步骤 1：维护家庭成员档案库**
添加全部家庭成员，填写饮食目标、过敏忌口、体质健康信息，保存档案。
2. **步骤 2：录入家中现有食材**
使用拍照 / 文字 / 武汉方言语音录入食材，确认食材列表。
3. **步骤 3：一键生成食谱方案**
获取全家共享菜品、个人分餐与营养评估；若食材不足输出智能采购清单。
4. **步骤 4：提交实际做菜反馈**
用户烹饪完成，勾选实际制作菜品与食用情况，可一键全选，提交反馈。系统保存饮食记录。
5. **步骤 5：周期性营养管理**
   - 单次食谱附带即时食材采购补充建议
   - 积累多日反馈数据，手动 / 自动生成每周营养分析报告，输出下周饮食调整建议

## 四、网页端现存问题 & 开发待修复清单

表格

| 状态 | 问题描述 | 优先级 |
| --- | --- | --- |
| ✅ 正常 | 录入食材可以正常存储 | - |
| ❌ BUG 阻塞 | 家庭成员档案提交后无法保存，生成食谱接口读取不到成员数据，无法进行个性化营养校验与分餐计算 | 最高 |
| ⚠️交互优化 | 页面操作顺序混乱；前端需要调整引导逻辑，引导用户**先完善家庭档案 → 再录入食材 → 再生成食谱** | 高 |

```
家庭档案库（持久存储） ←【强依赖】→ AI食谱生成引擎
现有食材库（持久存储） ←【强依赖】→ AI食谱生成引擎

AI食谱生成引擎 → 输出食谱、营养评估、采购清单
用户做菜反馈记录 → 数据源 → 周营养分析报告

二期拓展：面相/舌苔识别 → 补充更新家庭档案库
二期拓展：采购清单 → 对接美团买菜跳转入口
```
